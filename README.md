# 同一條街

普社課小組報告：用 Three.js 做的漫畫風 3D 遊戲取代投影片，上台約 9 分鐘、13 個段落。

## 怎麼開
雙擊 `game\index.html`，用 Chrome 開啟（要有網路：Three.js、字型、QR code、手機互動都從網路載入）。F 鍵全螢幕；WASD／方向鍵移動，Shift 快走，滑鼠拖曳轉視角。

## 上台用的按鍵
| 按鍵 | 功能 |
|---|---|
| 空白鍵 | 下一句／關閉卡片／確認（點對話框也可以） |
| N／B | 下一段／上一段 |
| M | 段落選單（↑↓ 選、Enter 跳過去） |
| P | 暫停 |
| T | 計時器：本段秒數／建議秒數，超時變紅 |
| 1／2／3 | 投票、訓練中心的選項 |
| WASD＋E | 家務小遊戲：走過去，按住 E 做家務；阿公叫人時先跑回去按住 E |
| Q | 叫出手機互動的 QR code |
| V | 靜音 |
| G | 後製特效開關（電腦跑不動時會自動先降畫質、再關掉；也可以手動按） |
| Shift+R（連按兩次） | 清空手機投票與叫名字的結果，每次上台前按一次 |

## 檔案
| 檔案 | 用途 |
|---|---|
| `game\` | 遊戲本體（`index.html`、`css\`、`js\`）；台詞都在 `game\js\data.js` |
| `game\CHANGELOG.md` | 修改紀錄 |
| `遊戲製作說明.md` | 技術規格與分階段製作計畫 |
| `進化企劃.md` | 遊戲目前進度與接下來要做的事 |
| `同一條街_劇本.md` | 劇本（另有 `_v0.2`、`初稿`） |
| `理論引文對照.md` | 三本書的引文（已對過原文）、每段扣哪個理論 |
| `ANTIGRAVITY.md` | 給 AI 協作者的規則 |
| `美術備份_*`、`*備份_*`、`*備份_*.js` | 修改前的備份 |
