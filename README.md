# 同一條街

普社課小組報告：用 Three.js 做的漫畫風 3D 遊戲取代投影片，上台約 9 分鐘、13 個段落。

## 怎麼開
雙擊 `game\index.html`，用 Chrome 開啟。F 鍵全螢幕；WASD／方向鍵移動，Shift 快走，滑鼠拖曳轉視角。

## 檔案
| 檔案 | 用途 |
|---|---|
| `game\` | 遊戲本體（`index.html`、`css\`、`js\`） |
| `game\CHANGELOG.md` | 修改紀錄 |
| `遊戲製作說明.md` | 技術規格與分階段製作計畫 |
| `同一條街_劇本.md` | 劇本（另有 `_v0.2`、`初稿`） |
| `ANTIGRAVITY.md` | 給 AI 協作者的規則 |
| `美術備份_*`、`*備份_*.js` | 修改前的備份 |
